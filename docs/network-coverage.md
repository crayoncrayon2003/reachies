# 関西の公共交通網：収録状況

鉄道は国土数値情報2025年度版、バス経路は2022年度版を使用。表示範囲は経度134.15〜136.90、緯度33.35〜35.85の矩形です。行政区域による厳密な切り出しではありません。下表の「収録」はこの範囲内の形状が入っている意味で、運行・乗換・自転車利用の可否を確認した意味ではありません。

鉄道180路線グループ／4,964区間／75,757頂点。路線・会社をまたぐ駅を統合した2,041駅と、バス停32,320地点を選択できます。原典の表示範囲内の全駅を取り込み、地方駅も丸を表示します。

バス資料には大阪シティバス・京都市・神戸市・阪急バス・京阪バス・神姫バス・近鉄バス・南海バス・奈良交通・江若交通・淡路交通などの事業者名があります。ただし、同資料は「事業者が通行する道路経路」であり、系統別ルートではありません。2026年現在の存廃・時刻表は未確認です。バスの乗車時間は未計算です。バス停からの徒歩・自転車圏は直線距離と移動速度から推定して表示します。バス路線と停留所は初期表示し、会社ごとに路線色を統一します。

個別系統の確認にはGTFSの `routes`, `trips`, `shapes`, `stop_times`, `calendar` 等が必要です。たとえば [京都市の案内](https://data.city.kyoto.lg.jp/dataset/00656/) から [京都市バスGTFS](https://ckan.odpt.org/dataset/kyoto_municipal_transportation_kyoto_city_bus_gtfs) が公開されていますが、本アプリの経路データには含まれません。
