# りーち～ず：アプリケーション仕様

## 目的

公共交通の駅・停留所を起点に、徒歩や自転車で訪問できるイベントを探し、駅・停留所・イベントを組み合わせた旅程を作成するWebアプリです。

公開サイト：https://crayoncrayon2003.github.io/reachies/

## 構成

- Viteでビルドする静的Webアプリです。
- 地図表示にはLeafletを使用します。
- 鉄道路線・駅・バス経路・停留所・イベントは `public/data/` から読み込みます。
- 到達圏の距離換算と旅程の編集はブラウザ内で処理します。
- GitHub Actionsでテストとビルドを実行し、GitHub Pagesに公開します。

## 地図と表示切替

対象範囲は経度134.15〜136.90、緯度33.35〜35.85です。鉄道は180路線グループ・2,041駅、バスは219事業者・自治体の経路と32,320停留所を収録しています。範囲と収録路線の詳細は [収録状況](network-coverage.md) を参照してください。

「地図の表示」は常時表示します。鉄道路線は路線別、バス経路は事業者別に切り替えられ、検索と一括切替が可能です。鉄道駅とバス停留所にも独立した表示切替があります。初期状態は全表示、ズーム14、選択駅は大阪・梅田と京橋です。

駅・停留所は丸、イベントは種類別の角形ピンで表示します。駅・停留所の丸は通常14px、複数路線がある地点は20pxで、ズーム中も画面上のサイズを維持します。同じ運営会社の路線は共通の色を使います。

## 到達圏

徒歩・自転車を選び、各区間の移動時間を5〜30分の範囲で指定します。到達圏は、選択した駅・停留所のいずれかから指定時間以内に届く場所の和集合です。

配信中の到達圏は直線距離に基づく推定です。移動速度は徒歩4.5km/h、自転車15km/hを使います。最寄りの選択地点からの所要時間に応じ、5分刻みの6段階で濃い赤から淡い赤へ色分けします。

道路・河川・橋・坂・通行規制は距離換算に含まれません。実道路の事前計算用スクリプトは `scripts/precompute.py` にあり、配信中のデータとは別に入力データの準備と計算が必要です。

## 旅程

出発地と到着地は公共交通の駅・停留所です。その間には任意の数の駅・停留所・イベントを配置でき、同じ地点を複数回訪問できます。

駅・停留所・イベントのポップアップから追加位置を選びます。経由位置は「1と2の間」のように番号で指定し、駅・停留所は出発地・到着地にも設定できます。経由地点は削除・並べ替えが可能です。到達圏用の駅選択だけでは作成済みの旅程は変わりません。

隣接する全地点を順に線で結び、訪問番号と区間番号を表示します。線は地点間の接続を示すもので、実際の道路経路や乗車経路ではありません。

区間ごとに徒歩・自転車・公共交通を選べます。徒歩・自転車の推定時間を各区間の時間上限と比較します。公共交通は駅・停留所間で指定できますが、乗車時間と接続は計算対象に含みません。時間が未計算の区間を含む旅程は、全体の実行可否を判定しません。

## データと制約

鉄道の形状・駅位置は国土数値情報2025年度版、バス経路・停留所は2022年度版に基づきます。収録イベントは架空の情報です。

バス経路の原典は事業者単位であり、系統別の形状は含まれません。高速バス・デマンド交通は原典の対象外です。現行の運行状況、時刻表、乗換、自転車の貸出返却、イベント開催時刻・滞在時間は旅程の判定に含みません。

出典・ライセンス・データ形式・起動方法・再生成手順は [README](../README.md) を参照してください。取り込み件数と加工条件は同ディレクトリの各 `*-import-report.json` に記録しています。
